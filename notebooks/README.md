# Initial Exploratory Data Analysis

Direktori ini akan digunakan untuk menyimpan notebook eksplorasi data
GBFS Citi Bike.

## Objectives

Eksperimen awal direncanakan untuk:

1. Memeriksa struktur `station_information` dan `station_status`.
2. Mengidentifikasi missing values dan duplikasi `station_id`.
3. Menganalisis distribusi jumlah sepeda tersedia.
4. Menganalisis distribusi slot dok kosong.
5. Mengidentifikasi stasiun yang hampir kosong atau penuh.
6. Mengamati perubahan ketersediaan berdasarkan waktu.
